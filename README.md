# ASAN müraciət — SwiftUI iPhone Prototype

Bu repoda iPhone üçün (yalnız SwiftUI) hazırlanmış **ASAN müraciət** prototip nümunəsi var.

## Fayl
- `ASANMuracietPrototype.swift` — bir faylda model, API kontraktı, mock service, ViewModel və SwiftUI ekranları.

## Əhatə edilən əsas funksiyalar
- Şəkil seçimi (PhotosPicker)
- Vizual materialın AI analizi üçün API qatının skeleti
- Avtomatik təsvir, kateqoriya və prioritet təyini
- Müraciət göndərmə axını
- İlkin və icra vizualı üçün uyğunluq yoxlaması (demo/mock)
- Uyğunsuzluq üçün xəbərdarlıq mexanizmi

## Qeyd
Bu bir **prototipdir**. Real mühitdə backend API, autentifikasiya, təhlükəsizlik, audit log, encrypted storage və model monitorinqi əlavə edilməlidir.
